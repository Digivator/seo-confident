# Security policy

## Supported versions

Security fixes are released for the latest version of SEO Confident. Please update to the newest release before reporting an issue.

| Version | Supported |
| --- | --- |
| 1.x | Yes |

## Reporting a vulnerability

Please do not report security problems in a public issue or pull request.

Use one of these private routes instead:

- **GitHub.** Open the repository's **Security** tab and choose **Report a vulnerability**.
- **Email.** Write to [info@digivator.co.uk](mailto:info@digivator.co.uk) with "SEO Confident security" in the subject line.

Please include:

- A description of the problem and where it sits in the code
- The plugin, WordPress and PHP versions you tested with
- Steps to reproduce it, or a short proof of concept
- Your view of the impact

## What to expect

- We aim to acknowledge your report within a week.
- We will confirm the problem, work on a fix and keep you updated.
- Once a fixed version is released, we are happy to credit you in the changelog unless you would rather stay anonymous.

Please give us reasonable time to release a fix before sharing details publicly.
